# Java Lab Experiments and ShopSphere Project

## Overview
This repository contains six Java lab experiments and the ShopSphere project developed for academic purposes.

## Lab Experiments

### Experiment 1: Calculator
A Java program to perform basic arithmetic calculations.

### Experiment 2: Student Registration
A student registration form using the technologies implemented in the project.

### Experiment 3: Server-Client Programming
A Java socket programming experiment demonstrating communication between a client and a server.

### Experiment 4: Remote Method Invocation (RMI)
A Java RMI experiment demonstrating remote method calls.

### Experiment 5: Servlet Programming
A Java Servlet experiment using the required web server configuration.

### Experiment 6: HTML to JSP
An experiment demonstrating form submission from HTML to a JSP page.

## ShopSphere Project
ShopSphere is a Java-based e-commerce project.

## Technologies Used
Java, and the additional technologies actually used in each experiment and project, such as MySQL, Servlets, JSP, HTML/CSS, or Apache Tomcat where applicable.

## Repository Structure
- Experiment-1-Calculator
- Experiment-2-Student-Registration
- Experiment-3-Server-Client
- Experiment-4-RMI
- Experiment-5-Servlet
- Experiment-6-HTML-to-JSP
- ShopSphere

## How to Run
Open each experiment or project in the appropriate IDE and follow its configuration requirements. Configure the necessary Java environment, server, database, and dependencies where applicable.

## Purpose
Academic submission of Java lab experiments and a Java-based project.
